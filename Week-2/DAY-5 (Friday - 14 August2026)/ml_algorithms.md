# Classic Machine Learning Algorithms

## 1. Linear Regression

### Type:
Supervised Learning

### Purpose:
Used to predict continuous numerical values.

### Example:
Predicting house prices based on size, location, and number of rooms.

### How it works:
Linear Regression finds the relationship between input features and output values by fitting the best line through the data.

### Applications:
- Price prediction
- Sales forecasting
- Trend analysis


---

# 2. Logistic Regression

### Type:
Supervised Learning

### Purpose:
Used for classification problems.

### Example:
Predicting whether an email is spam or not.

### How it works:
It calculates the probability of a class and assigns the input to the most suitable category.

### Applications:
- Spam detection
- Disease prediction
- Binary classification


---

# 3. Decision Tree

### Type:
Supervised Learning

### Purpose:
Used for classification and regression tasks.

### Example:
Loan approval prediction based on customer information.

### How it works:
Creates a tree-like structure where decisions are made based on feature conditions.

### Applications:
- Customer analysis
- Medical diagnosis
- Recommendation systems


---

# 4. K-Nearest Neighbors (KNN)

### Type:
Supervised Learning

### Purpose:
Classifies data based on similarity with nearby examples.

### Example:
Classifying a new customer based on similar customer behavior.

### How it works:
The algorithm checks the nearest data points and assigns the majority class.

### Applications:
- Pattern recognition
- Recommendation systems
- Classification problems


---

# 5. K-Means Clustering

### Type:
Unsupervised Learning

### Purpose:
Groups similar data points into clusters.

### Example:
Customer segmentation based on buying behavior.

### How it works:
The algorithm divides data into different groups based on similarity.

### Applications:
- Market segmentation
- Data analysis
- Image compression
