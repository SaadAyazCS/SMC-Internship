# Machine Learning Algorithm Comparison


| Algorithm | Learning Type | Main Use |
|------------|--------------|----------|
| Linear Regression | Supervised | Predict numerical values |
| Logistic Regression | Supervised | Classification |
| Decision Tree | Supervised | Classification & Regression |
| KNN | Supervised | Similarity-based classification |
| K-Means | Unsupervised | Data clustering |


## When To Use


### Linear Regression
Use when:
- Output is continuous
- Relationship between variables is mostly linear


### Logistic Regression
Use when:
- Output belongs to categories
- Example: Yes/No, True/False


### Decision Tree
Use when:
- Rules and decision-making are important
- Data has multiple conditions


### KNN
Use when:
- Similarity between examples matters


### K-Means
Use when:
- Data has no labels
- Need to discover hidden groups
